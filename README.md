# SCI website redirect

This repository only redirects visitors from https://sci.yonsei.ac.kr/ to https://sts.yonsei.ac.kr/.

The full website is maintained in `infosci/sts`. GitHub Pages publishes the root of the `gh-pages` branch. Keep `CNAME` and `.nojekyll`; `404.html` redirects old or unknown paths to the new homepage.

The `main` branch holds the same redirect files. Previous site content remains in Git history.
